Character editor

Paste changes to a resident's design, or to the poses of the correction scene, and see them here. Saved changes are used by the game the next time a scene is built, in this browser.

Who

Preview

Design

A JSON object with only the fields to change ({"height":172,"outfit":{"hair":"#5a1e12"}}), or a whole preset as the character viewer's “Show JSON” prints it. Colours may be numbers, 0xrrggbb or "#rrggbb". Objects merge; arrays replace; null removes a field.

Poses

Paste the character viewer's pose-editor report, or JSON like {"position":"case","who":"subject","beat":"base","bones":{"neck":[-40,0,0]}} (an array also works). Angles are the engine's pose-table Euler degrees [x, y, z]. Where the scene itself drives a joint (the swinging arm's IK), the report's table value is used. Positions: lap, case, head, chair, spread.
